# Youth FireSafe NTB

Website edukasi keselamatan kebakaran untuk masyarakat Nusa Tenggara Barat (NTB). Berisi materi pencegahan kebakaran, evakuasi, penggunaan APAR, pertolongan pertama, berita kebakaran, kuis, dan daftar nomor darurat.

🌐 Website: https://youthfiresafentb.github.io/youthfiresafentb/

## Struktur Folder

```
├── index.html      Halaman utama (seluruh CSS dan JavaScript ada di dalamnya)
├── favicon.png     Ikon tab browser
├── logo.jpg        Logo, juga dipakai sebagai gambar pratinjau saat link dibagikan
├── robots.txt      Aturan untuk mesin pencari
├── sitemap.xml     Peta situs untuk mesin pencari
└── foto/           Gambar untuk kartu berita, press release, dan halaman materi
```

## Daftar Foto di Folder `foto/`

| File | Dipakai untuk |
|------|---------------|
| `moyo.jpg`, `tambora2.jpg`, `tente.jpg`, `alas.jpg`, `sade.jpg`, `doroo.jpg`, `pagutan.jpg`, `tambora1.jpg`, `banggo.jpg` | Berita |
| `damkar.jpg` | Press release |
| `materi1.jpg` sampai `materi6.jpg` | Halaman materi |

Gambar di folder ini adalah **gambar pengganti** bermerek Youth FireSafe NTB. Untuk memakai foto dokumentasi asli, cukup timpa file dengan nama yang **sama persis**:

- huruf kecil semua dan berekstensi `.jpg` (bukan `.jpeg` atau `.JPG`)
- disarankan rasio sekitar 16:9 (misalnya 1200 × 630 px)
- disarankan di bawah 300 KB per file supaya website tetap cepat

## Cara Menjalankan di Komputer

Cukup buka `index.html` di browser. Tidak perlu instalasi apa pun.

## Cara Publikasi

**Netlify (saat ini):** hubungkan repository ini ke Netlify, atau seret folder proyek ke dashboard Netlify.

**GitHub Pages:**
1. Buka **Settings → Pages**.
2. Pada *Branch*, pilih `main` dan folder `/ (root)`, lalu **Save**.
3. Website tersedia di `https://username.github.io/nama-repo/`.
4. Ganti alamat `https://youthfiresafentb.netlify.app/` di `index.html`, `robots.txt`, dan `sitemap.xml` dengan alamat baru.
